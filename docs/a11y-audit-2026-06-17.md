## 🟠 Level A High

### 위반 1: accessible name 기본값 없음
- **파일:줄**: `Switch.tsx:118` (`<label>`) + `:119-129` (`<input>`)
- **WCAG SC**: 4.1.2 Name, Role, Value (A) / 1.3.1 (A)
- **발견 코드**: `<label>` 안에 텍스트 0, `<input role="switch">`는 `{...rest}`로 aria-label "가능"만 — 강제·문서화 X.
- **장애 시나리오**: 맨 `<Switch />`는 스크린 리더가 "스위치, 켜짐"으로만 읽음 → 무엇을 켜는지 정보 0. 시각장애 사용자(한국 약 25만명) + 음성입력 사용자는 필드 의미 파악 불가.
- **수정 가이드**:
  ```tsx
  // 컴포넌트가 label 연결을 강제/문서화 (둘 중 하나)
  // ① 외부 <label htmlFor> 또는 aria-labelledby 연결을 props 타입으로 요구
  // ② 또는 aria-label 필수임을 README/JSDoc에 명시
  ```
- **false-positive 주의**: 소비자가 항상 `aria-label`/외부 `<label>`을 연결하면 실사용에선 문제 없음. 단 **컴포넌트가 그것을 보장하지 않음** = 잘못 쓰기 쉬움.
